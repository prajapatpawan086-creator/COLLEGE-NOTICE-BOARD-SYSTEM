# College Digital Notice Board System

A web-based College Notice Board mini-project built using **HTML, CSS, and JavaScript**. This project allows faculty members to publish important notices and students to view, search, and filter circulars online.

## Features
- **Publish Notices:** Faculty can post new notices with a security PIN (`1234`).
- **Urgent Highlighting:** Important notices are highlighted with an `URGENT` tag and red border.
- **Category Filter:** Filter circulars by *Academic, Examination, Events, Placement,* or *Administration*.
- **Instant Search:** Search any notice by keywords or title.
- **Local Storage Support:** Notices remain saved in the browser even after refreshing the page.

## Tech Stack
- **HTML5** (Page Structure)
- **CSS3** (Flexbox Layout & Responsive Design)
- **Vanilla JavaScript** (DOM Manipulation & `localStorage`)
